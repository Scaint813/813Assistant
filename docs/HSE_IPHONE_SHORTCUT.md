# HSE App → 813Assistant на iPhone

HSE App создаёт системный календарь с точным именем `HSE` и обновляет его при
входе в приложение. Сервер не получает доступ к iCloud: iPhone сам выбирает
только пары на ближайшие 14 дней и отправляет их в закрытый endpoint.

## 1. Проверить HSE App

1. В HSE App открой `Профиль → Экспорт в Календарь`.
2. Включи `Синхронизация с Календарём` и выбери `iCloud`.
3. Войди в HSE App, затем в системном приложении `Календарь` проверь событие в
   календаре `HSE`.

## 2. Получить данные подключения

В Telegram нажми `Управление → Профиль → Календарь HSE с iPhone → Настроить
автоматизацию`. Скопируй отдельно:

- URL;
- полный заголовок `Authorization`, включая слово `Bearer`.

Токен нельзя отправлять в чат или добавлять в URL. Экран доступен только
владельцу через проверенную сессию Telegram Mini App.

## 3. Собрать команду «Синхронизировать HSE»

В приложении `Команды` создай новую команду:

1. `Текущая дата` → сохрани как начало периода.
2. `Настроить дату` → прибавить 14 дней → сохрани как конец периода.
3. `Найти события календаря`:
   - `Календарь` — `HSE`;
   - дата начала — между началом и концом периода;
   - сортировка — по дате начала, сначала ранние.
4. Создай пустую переменную-список `Events`.
5. `Повторить с каждым` найденным событием. Внутри повтора сначала примени
   действие `Форматировать дату` к дате начала и дате окончания, выбрав формат
   `ISO 8601`. Затем создай словарь:

   | Ключ | Значение из повторяемого события |
   |---|---|
   | `id` | Идентификатор, а если его нет — Заметки |
   | `title` | Название |
   | `start` | Дата начала в формате ISO 8601 |
   | `end` | Дата окончания в формате ISO 8601 |
   | `calendar` | Имя календаря (`HSE`) |
   | `location` | Местоположение |
   | `notes` | Заметки |

6. Добавь словарь в переменную `Events`.
7. После повтора создай словарь: ключ `events`, значение — список `Events`.
8. Добавь `Получить содержимое URL`:
   - URL — скопированный из Mini App;
   - метод — `POST`;
   - тело запроса — `JSON`, созданный словарь;
   - заголовок `Authorization` — скопированное значение целиком.
9. Назови команду `Синхронизировать HSE` и запусти один раз вручную. Успешный
   ответ содержит `"status":"saved"` и число событий.

## 4. Запускать после обновления HSE App

1. В `Команды → Автоматизация` создай личную автоматизацию `Приложение`.
2. Выбери HSE App и условие `Закрыто`.
3. Выбери `Запускать немедленно` и действие `Запустить команду` →
   `Синхронизировать HSE`.

HSE App обновляет календарь при входе, поэтому запуск после закрытия устраняет
гонку: сначала новые пары появляются в iOS, затем уходят в планнер. Автоматизации
по событию закрытия приложения могут работать без дополнительного подтверждения
пользователя согласно документации Apple:
[Setting triggers](https://support.apple.com/guide/shortcuts/apde31e9638b/ios),
[Enable personal automation](https://support.apple.com/guide/shortcuts/apd602971e63/ios).

## Что отправляется

Только название, начало, конец, аудитория/адрес, заметки и стабильный ID событий
из календаря `HSE`. Endpoint дополнительно отбрасывает любой элемент, у которого
имя календаря отличается. События календарей `Личный`, `Работа`, `Семья` и
других источников не сохраняются.
