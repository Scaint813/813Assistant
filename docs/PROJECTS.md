# «Мои проекты»

Вкладка `Проекты` содержит личный каталог сервисов владельца:

- `VPN` открывает внутреннюю панель проверки Tailscale и внешнего IP.
- `813spam` открывает отдельно настроенную панель проекта.

Каталог загружается независимо от профиля и календаря через
`GET /api/v1/projects`. Endpoint принимает подписанную Telegram-сессию и
доступен только `ALLOWED_USER_ID`: другие пользователи из allowlist получают
403. Ответы не кэшируются в HTTP. До успешной авторизации и после её потери
ссылки не показываются; неудачный повтор запроса не восстанавливает старые
приватные данные.

Это каталог личных сервисов, не изменение модели задач `Project` в БД.
Миграция базы для него не нужна.

## Ссылка на 813spam

На сервере ассистента задайте публичный адрес панели:

```dotenv
PROJECT_813SPAM_URL=https://your-panel.example.com/
```

Адрес должен быть HTTPS, без логина/пароля, query-параметров, fragment и
управляющих символов. Некорректный или пустой адрес отключает только переход
813spam, а не весь ассистент. Mini App не запрашивает адрес с сервера:
переход выполняется браузером, без Telegram `Authorization` и `initData`.
Ссылка открывается с `noopener noreferrer`.

После изменения `.env` перезапускают только `813assistant`. VPN продолжает
работать независимо от панели. Не копируйте пароль 813spam в `.env` ассистента
или URL ради автоматического входа.

## Автоматический вход

В этой версии переход является обычной ссылкой. Флаг
`automatic_login_available=false` намеренно не выдаёт его за настроенный
автовход. Если панель 813spam требует пароль, её текущая авторизация
продолжает действовать.

Для входа именно из Mini App без повторного пароля нужна интеграция обеих
сторон: ассистент проверяет владельца по Telegram, затем целевой сервис
однократно принимает короткоживущий допуск и создаёт собственную защищённую
сессию. Проверка назначения, срока действия и защита от повторного
использования должны выполняться в 813spam. Без исходников и проверки её
действующего механизма авторизации такую интеграцию нельзя считать готовой.

Постоянный пароль не должен оказаться в HTML/JavaScript, браузерном хранилище,
ссылке, истории или журнале запросов. Передавать Telegram `initData` в URL
другого приложения также не требуется.

## Проверка

1. Владелец видит отдельные карточки VPN и 813spam во вкладке «Проекты».
2. Возврат из VPN ведёт в «Мои проекты», активной остаётся вкладка «Проекты».
3. Без URL переход 813spam выключен; при корректном URL открывается ровно
   этот адрес. Подпись не обещает автоматическую авторизацию.
4. Без подписи API возвращает 401, другому разрешённому пользователю — 403.
5. Ошибка каталога не мешает переключению остальных основных разделов.
